# ROBOXENCE 2026 — Frontend Application

High-performance, futuristic cyberpunk web application for **ROBOXENCE 2026** (Department of Robotics & Artificial Intelligence, SVPCET Nagpur).

---

## 🚀 Tech Stack & Features
- **Core**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Futuristic Cyberpunk Glassmorphism & Metallic Chrome typography
- **Canvas Physics**: Relativistic Gravitational Blackhole (*Gargantua*) & Keplerian accretion disk simulation
- **Audio Synthesizer**: Web Audio API ambient low-frequency sci-fi atmospheric drone
- **Data Layer**: Direct Firebase Firestore client reads with resilient built-in fallback
- **Registration**: Direct Google Forms integration with customizable external links
- **Modular Components**:
  - `Navbar`: Sticky cyber navigation with college emblem & atmosphere audio toggles
  - `Hero`: Metallic typography & festival CTAs
  - `EventsSection`: Dynamic Firestore-loaded event arenas
  - `EventDetailsModal`: Poster showcase, full dossiers, guidelines & cash prizes ("Upto ₹X/-")
  - `TeamSection`: Departmental Command Central & coordinator contacts
  - `ContactSection`: Campus venue details & official social channels

---

## 🛠️ Local Development

### 1. Install Dependencies
```bash
cd frontend
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

### 3. Run Dev Server
```bash
npm run dev
```
The application will be accessible at: `http://localhost:5173`

---

## 📦 Production Build
```bash
npm run build
npm run preview
```
